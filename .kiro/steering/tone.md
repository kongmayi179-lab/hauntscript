# Tone & writing

- Voice: gothic, slightly dry, Infocom-adjacent. Short paragraphs.
- Avoid: gore for shock, slurs, copyrighted characters, modern meme slang in room text.
- Parser failure messages: polite and brief ("I don't understand that. Type help.").
- Dark rooms: reference classic IF darkness tropes lightly; never soft-lock without a recoverable path (lantern + matches exist in-world).
- Ending: cathartic, not nihilistic — the curse sleeps until next Halloween.
